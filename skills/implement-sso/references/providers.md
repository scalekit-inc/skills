# Provider notes

IT admins configure the customer's IdP in the admin portal. Do not paste IdP click-paths into app code. Share the matching live guide with the portal link.

Index: https://docs.scalekit.com/guides/integrations/sso-integrations/

| IdP | SAML | OIDC |
|---|---|---|
| Okta | [okta-saml](https://docs.scalekit.com/guides/integrations/sso-integrations/okta-saml/) | [okta-oidc](https://docs.scalekit.com/guides/integrations/sso-integrations/okta-oidc/) |
| Microsoft Entra ID (Azure AD) | [azure-ad-saml](https://docs.scalekit.com/guides/integrations/sso-integrations/azure-ad-saml/) | [microsoft-entraid-oidc](https://docs.scalekit.com/guides/integrations/sso-integrations/microsoft-entraid-oidc/) |
| Google Workspace | [google-saml](https://docs.scalekit.com/guides/integrations/sso-integrations/google-saml/) | [google-oidc](https://docs.scalekit.com/guides/integrations/sso-integrations/google-oidc/) |
| JumpCloud | [jumpcloud-saml](https://docs.scalekit.com/guides/integrations/sso-integrations/jumpcloud-saml/) | [jumpcloud-oidc](https://docs.scalekit.com/guides/integrations/sso-integrations/jumpcloud-oidc/) |

The admin portal shows the ACS URL, Entity ID, and attribute names to paste into the IdP. Other providers: use the same index.
